# Agreed Acceptance Criteria

These criteria define the minimum standard for Mettelo sign-off.

1. **AC1:** Core workforce and turnover datasets are joined only at a documented compatible grain; unsupported joins are explicitly rejected.
2. **AC2:** Headcount and FTE are separately defined and no KPI silently mixes the two.
3. **AC3:** At least three longitudinal validation checks reconcile derived values to published/source totals where feasible.
4. **AC4:** Organisation/staff-group code changes or discontinuities affecting trend analysis are documented.
5. **AC5:** If forecasting is used, a naive baseline and time-aware validation are included and uncertainty is shown.
6. **AC6:** No output is described as a safe-staffing judgement or direct measure of care quality.
7. **AC7:** Dashboard headline values reconcile to the curated analytical model for agreed test organisations/staff groups.
8. **AC8:** A reviewer can reproduce the selected workforce series, analysis and dashboard-ready tables from the documented public files without undocumented manual intervention.

## Sign-off Rule

The project is not complete because all files exist. The review panel must be able to verify the business, data, analytical, product and reproducibility criteria above from repository evidence.

## Evidence Mapping

The team should maintain a simple table mapping each acceptance criterion to:
- requirement(s);
- artefact(s);
- test/reconciliation evidence;
- owner;
- status.
