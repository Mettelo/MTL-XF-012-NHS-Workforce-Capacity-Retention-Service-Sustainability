# Mandatory Team Repository Standard

Create the delivery repository under the **Mettelo GitHub organisation** using:

`MTL-XF-012-<team-name>`

Add every team member using their individual GitHub account.

Required folders: `data/`, `docs/01-discovery/`, `docs/02-data-governance/`, `docs/03-data-model/`, `docs/04-data-quality/`, `docs/05-kpi-catalogue/`, `docs/06-analysis/`, `docs/07-decision-framework/`, `docs/08-assurance-uat/`, `docs/09-technical-handover/`, `sql/`, `src/`, `notebooks/`, `analysis/`, `dashboard/`, `deliverables/`, `submission/`.

Use issues, meaningful commits, branches, PRs and reviews where practical. One final bulk upload by one person is not appropriate collaborative evidence. `CONTRIBUTIONS.md` records actual contribution; commit count alone is not proof of capability.
