# Submission Guide

1. Create `MTL-XF-012-<team-name>` under the Mettelo GitHub organisation.
2. Add all team members individually.
3. Build the mandatory repository structure.
4. Deliver through GitHub throughout the project.
5. Complete D1–D12.
6. Confirm data/source reproducibility, governance, UAT, contribution evidence and no committed secrets.
7. Complete `submission/FINAL_SUBMISSION.md`.
8. Tag the final version `v1.0-mettelo-submission`.
9. Submit the repository URL to Mettelo.
