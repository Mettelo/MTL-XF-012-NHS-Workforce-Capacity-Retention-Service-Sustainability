# Data Workspace

**Primary dataset:** NHS HCHS Workforce Statistics — July 2026, including core workforce and turnover extracts  
**Publisher:** NHS England  
**Format:** ZIP/CSV and XLSX  
**Official source:** https://digital.nhs.uk/data-and-information/publications/statistical/nhs-workforce-statistics/july-2026

Mettelo uses a frozen cohort version/reference so the project remains reproducible if the publisher later changes its website. Preserve raw files unchanged and record version/acquisition details in `SOURCE_REGISTER.md`.
